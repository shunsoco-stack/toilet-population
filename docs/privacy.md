# データとプライバシーについて

世界トイレ人口は、このアプリで「今トイレです」を押している状態を共有する遊びのアプリです。世界の実際のトイレ利用者数を測定・推計するものではなく、健康状態の診断や行動の正確な記録を目的としたものでもありません。

## 入力・許可を求めない情報

氏名、メールアドレス、住所の入力は求めません。ブラウザーの位置情報APIは使わず、GPSや現在地のアクセス許可も求めません。画面内の世界をイメージした装飾は実際の所在地を表していません。

## Firebase設定時に共有される情報

Firebase Anonymous Authenticationにより、ブラウザーに匿名の識別子（UID）が割り当てられます。Cloud Firestoreには `activeSessions/{uid}` として開始日時 `startedAt` と期限日時 `expiresAt` だけを保存します。氏名・メールアドレス・位置情報をこのドキュメントへ保存することはSecurity Rulesでも許可しません。

人数表示のため、匿名認証済みの利用者はセッションの日時とドキュメントIDを読み取れます。匿名UIDは実名ではありませんが、完全に情報が見えない仕組みではありません。過去の日時もTTL削除が完了するまではデータベース内に残る場合があります。

「トイレを出ました」で自分のセッションを削除します。開始から10分経つと人数の対象から除外します。ブラウザーを閉じている間など、サーバー上の物理的な削除はFirestore TTLによる後処理を待つことがあります。TTLは運営者による設定が必要です。

Firebaseが未設定のデモモードではFirebaseへセッション情報を送信しません。

## このブラウザーに保存する情報

- 本日の回数・合計時間を計算するための開始・終了の記録。
- 再読み込みや画面を閉じた後に状態を復元するための記録。
- 表示テーマなどの設定。

これらはブラウザーのlocalStorage等に保存します。端末間のバックアップや同期はしません。共有端末では同じブラウザープロファイルの利用者が記録を確認できることにご注意ください。ブラウザーのサイトデータを削除すると記録・設定や匿名認証状態が失われます。保存を許可しない環境では再読み込み後に復元できない場合があります。

## アクセス解析と通信サービス

Vercel Web Analyticsでページの閲覧状況を把握します。開始・終了・共有のカスタムイベント送信処理も実装していますが、現在のHobbyプランではカスタムイベントは収集されず、利用には対応するPro／Enterpriseプランが必要です。アプリのイベントに匿名UID、メールアドレス、氏名、GPS情報は含めません。Do Not TrackまたはGlobal Privacy Controlが有効なブラウザーでは、アプリからの解析イベント送信を抑止します。

VercelやFirebaseはサービス提供のため、通信時のIPアドレス、ブラウザー情報などのメタデータを処理する場合があります。Vercel Analyticsには接続情報に基づく大まかな地域情報が含まれる場合があり、「位置情報APIの許可を求めない」ことと「サービス提供者が接続情報を一切処理しない」ことは異なります。詳しくは[Vercel Analyticsのプライバシー説明](https://vercel.com/docs/analytics/privacy-policy)と[Firebaseのプライバシーとセキュリティ](https://firebase.google.com/support/privacy)をご確認ください。

## 共有

共有は利用者が共有ボタンを操作したときに実行します。端末の共有機能やクリップボードを利用し、アプリの紹介文とURLを共有します。個人の日時記録や匿名UIDを共有文へ含める必要はありません。端末の共有画面では、送信先と内容を確認してから送信してください。
